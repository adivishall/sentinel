# Hackathon submission (historical)

This folder is the original entry to the Mastercard Innovation Challenge @ GFF
2026: the write-up, deck, demo script, charts and gallery for **Sentinel v1**,
a four-layer firewall around a bank's LLM agents.

It is kept as a record, not maintained. The architecture, the numbers and the
console shown here predate version 2 and are **not** the current system or its
current results. For those, see the [root README](../README.md),
[docs/EVALUATION.md](../docs/EVALUATION.md) and
[docs/LIMITATIONS.md](../docs/LIMITATIONS.md); the v1 technical documents are in
[docs/archive/](../docs/archive/).
